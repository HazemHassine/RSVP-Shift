# Fast Reader

Fast Reader is a Chrome extension that speed-reads any selected text with RSVP (rapid serial visual presentation).

## Features

- Start or stop reading with a shortcut or the popup button
- Adjustable WPM, jump size, pivot color, and background dim
- Progress bar and punctuation-aware pauses

## Install (Developer Mode)

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and choose this folder.

## Usage

1. Select text on any page.
2. Press `Ctrl+Shift+Q` (or `Command+Shift+Q` on Mac), or click the extension icon and press **Start/Stop**.
3. Use the controls in the overlay or the popup settings page.

## Shortcuts

- Start/Stop: `Ctrl+Shift+Q` / `Command+Shift+Q`
- Pause/Resume: `Space`
- Close: `Esc`
- Speed up/down: `↑` / `↓`
- Jump forward/back: `→` / `←`

## Settings

Settings are saved with `chrome.storage.sync` and apply across tabs.

## Notes

You can update shortcuts in Chrome at `chrome://extensions/shortcuts`.
